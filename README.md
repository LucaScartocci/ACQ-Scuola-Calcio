# ACQ Scuola Calcio · Fase 6I

## Restyling area caricamento file

- etichette Titolo e File perfettamente allineate
- campi con la stessa altezza
- selettore file personalizzato
- pulsante `CARICA FILE` più compatto e coerente
- formati supportati mostrati in modo discreto
- nome e dimensione dei file selezionati
- pulsante X per rimuovere un file prima dell'upload
- adattamento desktop, iPad e iPhone
- nessuna modifica al sistema di salvataggio già funzionante

## Installazione

Non servono query SQL.

1. Caricare tutti i file su GitHub sovrascrivendo quelli esistenti.
2. Conservare `.github`.
3. Attendere il deploy verde.
4. Aggiornare forzatamente il browser o riaprire la PWA.
