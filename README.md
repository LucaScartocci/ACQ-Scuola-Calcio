# ACQ Scuola Calcio

Archivio metodologico della Scuola Calcio Acquacetosa.

## Pubblicazione GitHub Pages

1. Caricare `index.html` e `.nojekyll` nella radice del repository.
2. Aprire **Settings → Pages**.
3. In **Build and deployment**, scegliere:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/(root)`
4. Salvare.
