# ACQ Scuola Calcio · Fase 6L Stable

## Notifiche navigabili

- click su una nuova sessione: apre la categoria corretta, mostra la seduta e la evidenzia
- click su Riunioni tecniche: apre direttamente la relativa libreria
- click su Materiale didattico: apre direttamente la relativa libreria
- la notifica viene segnata come letta al click
- navigazione interna senza ricaricare la pagina
- pulsante esplicito Vai alla sessione / Apri documenti
- scadenze Segreteria cliccabili
- click su certificato o tesseramento: apre il tesserato e mette in evidenza il documento

## Installazione

Non servono nuove query SQL. La query della Fase 6J deve essere già stata eseguita.

1. Caricare tutti i file su GitHub sovrascrivendo quelli esistenti.
2. Conservare `.github`.
3. Attendere il deploy verde.
4. Fare logout/login e aggiornare forzatamente il browser.
